## 2. Điểm mạnh nhất: Concept rất rõ (8.5/10)

Không phải "một trang chứng khoán CRUD" — đang xây dựng **môi trường mô phỏng đầu tư**:

Dashboard → Nhiệm vụ → Tin tức → Doanh nghiệp → Giao dịch → Mentor → Cộng đồng → Cuộc thi → Heatmap → Risk → NAV → Portfolio

Đây là **product ecosystem**, không phải các page riêng lẻ.

## 3. Visual Design: khá đẹp nhưng đang "dashboard template"

**Điểm tốt:**
- Dark theme + xanh lá = hợp lý
- Nền gần đen, card tối, border mảnh, accent xanh lá
- Typography mạnh, icon đồng nhất, badge/tag, số liệu lớn
- Người dùng hiểu ngay: **nền tảng mô phỏng giao dịch tài chính**

**Vấn đề chính: quá nhiều "khung" (card)**
- Mọi thứ đều nằm trong border/card → không có thứ gì thực sự nổi bật
- Sai lầm phổ biến khi thiết card dashboard

**Nên card hóa:** Portfolio, Nhiệm vụ, Biểu đồ, Order book
**Không cần card:** Một số KPI, Navigation, text phụ, filter
**Thay bằng:** background + spacing thay vì background + border + shadow + card

## 8. 🔴 News page — lỗi nghiêm trọng nhất

**Lỗi template không render:**
```
{name}
{symbol}
```

→ Hiển thị template variable thay vì dữ liệu thật. **Đây là bug sản phẩm**, không phải vấn đề UI.

**Lỗi dữ liệu timestamp hiển thị sai:**
```

```

→ Likely lấy timestamp/Unix time thay vì impact value. **Mapping API → frontend sai.**

## 20. Thứ tự sửa (P0 → P1 → P2)

### 🔴 P0 — Bắt buộc sửa

1. **Sửa toàn bộ dữ liệu lỗi**
   - `{name}`, `{symbol}`, `1777654800000.0`, `1785517200000.0`, `176720040000%`
   - Không được tồn tại trong bản demo

2. **Sửa Trade**
   - Price chart + Current price + Change + Order book
   - Nếu chưa realtime thì dùng simulated realtime
   - Cảm giác thị trường đang sống

3. **Kiểm tra toàn bộ data mapping**
   - Tạo lớp format: `formatCurrency()`, `formatPercent()`, `formatImpact()`, `formatDate()`, `formatNumber()`
   - Không render raw API data trực tiếp

### 🟠 P1 — Nâng UX

**Dashboard:**
- Thêm Portfolio performance, Recent activity, Market overview
- Bớt feature card

**Trade:**
- Order confirmation
- Order history / Open orders / Executed orders

**News:**
- Sentiment + Impact + Related stock + Price reaction

**Social:**
- Liên kết post với thị trường (mã, giá, thay đổi)

### 🟡 P2 — Visual polish

Sau khi logic hoàn chỉnh mới làm:
- spacing, typography, border, icon, animation, hover
- skeleton loading, empty states, error states
- responsive
